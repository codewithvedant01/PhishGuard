# PhishGuard — Interactive Cybersecurity & Scam Awareness Simulator

An interactive, responsive web application designed for campus outreach to educate school and college students in rural areas about online scams, phishing SMS, fake bank alerts, and social engineering tricks.

---

## 🌟 Key Features

1. **Spot-the-Scam Interactive Simulator**:
   - Realistic mock SMS and WhatsApp alerts based on real-world Indian scam templates (Electricity disconnection, SBI KYC freeze, PM Free Smartphone scheme, Work-From-Home task fraud).
   - Instant visual feedback, score tracking, and detailed breakdown of scam indicators and red flags.
2. **Suspicious URL & Domain Inspector**:
   - Educational analyzer checking for deceptive brand keywords, IP addresses, dangerous top-level domains (`.xyz`, `.top`, `.tk`), and insecure protocols.
   - Preloaded with real-world sample URLs for classroom demonstration.
3. **Cyber Red Flags Guide**:
   - Illustrated rules highlighting artificial urgency, lottery traps, remote screen-sharing fraud, and the golden UPI rule (*"PIN is only for sending money, never receiving"*).
4. **National Emergency Helpline & Golden Hour Steps**:
   - Direct information on national cyber helpline **1930** and **cybercrime.gov.in**, with step-by-step immediate actions following fraud.
5. **Bilingual Support (English & Hindi)**:
   - Instant language switch to cater specifically to rural audiences.

---

## 🚀 How to Run Locally

1. Simply double click `index.html` or open it in any web browser (Chrome, Edge, Firefox, Safari).
2. Or use Python's built-in local web server:
   ```bash
   python -m http.server 3000
   ```
   Open `http://localhost:3000` in your browser.
